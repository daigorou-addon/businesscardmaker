## 日本語

テンプレートを選んで入力するだけで、表裏の名刺を作成・印刷できるWebツールです。インストール不要で、PC・スマホの両方で使えます。

すべての処理はお使いの端末内で行われます。入力内容や画像がどこかに送信されることはありません。

**👉 [今すぐ使う](https://daigorou-addon.github.io/businesscardmaker/)**

### 主な機能

- **標準サイズの名刺**: 91mm × 55mm（日本の標準サイズ）
- **テンプレート**: 表面12種・裏面6種から選択
- **アクセントカラー**: テンプレートの色を自由に変更（なしも選択可）
- **表面・裏面**: 「裏面も作成する」をオンにすると、裏面のテンプレートを選べます
- **入力項目**: 会社名・屋号 / 氏名 / ふりがな / 部署 / 役職 / 郵便番号・住所 / 電話番号 / FAX / メールアドレス / URL / LINE ID / Instagram ID
- **裏面用項目**: 英語社名 / 英語氏名（ローマ字） / 英語住所 / 事業内容・取扱品目
- **ロゴ画像**: 任意で追加。プレビュー上でドラッグして移動、右下の丸をドラッグしてサイズ変更
- **すべてクリア**: 入力内容をまとめて消去
- **PNG保存**: 300dpi相当の画像として保存
- **印刷**: 91mm × 55mm のサイズで印刷
- **表示テーマ切り替え** と **6言語対応**（日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español）

### 使い方

1. 表面のテンプレートとアクセントカラーを選びます。
2. 「名刺の内容」に会社名・氏名などを入力します。プレビューにすぐ反映されます。
3. 裏面も作る場合は「裏面も作成する」をオンにして、裏面のテンプレートと項目を設定します。
4. 「画像を保存（PNG）」または「印刷」で出力します。

## English

BusinessCardMaker is a web tool for creating and printing front-and-back business cards by picking a template and filling in your details. No installation is required, and it works on both desktop and mobile.

Everything is processed on your own device. Your input and images are never sent anywhere.

**👉 [Try it now](https://daigorou-addon.github.io/businesscardmaker/)**

### Features

- **Standard card size**: 91mm × 55mm (the standard size in Japan)
- **Templates**: choose from 12 front designs and 6 back designs
- **Accent color**: change the template color freely (or choose none)
- **Front and back**: turn on "Create the back side too" to pick a back-side template
- **Fields**: company / name / name reading (furigana) / department / job title / postal code and address / phone / fax / email / URL / LINE ID / Instagram ID
- **Back-side fields**: company name in English / name in English (romanized) / address in English / business description
- **Logo image**: optional. Drag it on the preview to move it, and drag the circle at the bottom right to resize it
- **Clear all**: erase everything you entered in one click
- **PNG export**: saved as an image at 300 dpi equivalent
- **Print**: prints at 91mm × 55mm
- **Light/dark theme** and **6 languages** (日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español)

### Usage

1. Choose a front-side template and an accent color.
2. Enter your company name, name, and other details under "Card content". The preview updates instantly.
3. To make a back side too, turn on "Create the back side too" and set up the back template and fields.
4. Export with "Save image (PNG)" or "Print".
